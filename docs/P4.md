CHROME_EXECUTABLE="/path/to/chrome" node scripts/voice-replay.mjs

an alternate clip directory and repeat count are positional arguments. `WEB_URL`
and `VOICE_WS` override local endpoints. See [eval instructions](../evals/README.md).
