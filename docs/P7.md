# P7 — rehearsal and audit

P7 adds a deterministic red-team audit and an opt-in field rehearsal runner.
The audit exercises the existing grounding, privacy, CAT termination, shared
engine, roadmap, ablation, i18n, P3 and P5 gates. It runs without provider or
database writes.

The field runner accepts an independently reviewed Telugu microphone clip and
reference transcript. It bypasses the ASR rehearsal cache, LLM response cache,
and TTS cache, then reports:

- word error rate (WER), character error rate (CER), and bounded transcript
  accuracy from the live ASR response;
- first real audio and total voice-turn p95;
- provider names, event sequence, sample counts, and explicit blocked reasons.

It never treats browser-final text, synthetic Web Audio, cached ASR, or cached
TTS as field accuracy or uncached latency.

## Reproduce

From the repository root:

```sh
uv run --project apps/api python evals/run_p7.py --audit
```

For a real reviewed clip:

```sh
uv run --project apps/api python evals/run_p7.py \
  --audio /path/to/reviewed-telugu-clip.webm \
  --reference /path/to/reviewed-telugu-clip.txt \
  --locale te --samples 1 --reviewed \
  --review-note "independent review source and clip provenance" --require-field
```

The reference transcript must be prepared independently of the ASR result.
`--reviewed` is an explicit operator attestation that the recording is a real
Telugu microphone clip and the reference was independently checked. Audio is
limited to 4.5 MB and a run to 20 samples. The report stores provider, event
sequence and transcript error counts/ratios, but never stores the recognized
or reference transcript text. `--review-note` records the independent review
source and clip provenance.
The command writes `evals/p7_report.json`; raw audio is not copied into the
repository.

P7 phase readiness requires the deterministic audit and reviewed field
evidence. The deterministic audit also checks the P4 cached browser/server
latency gates. P7's uncached voice latency is reported as field evidence; it
does not replace the build plan's cached-clip gate. WER/CER are reported for
review; the plan does not define a field accuracy threshold. P7 readiness is
separate from full build readiness.

## Current result

The deterministic audit passes. It confirms that invented numbers and payment
instructions are struck, notice contact data is removed, CAT stops at six
answers, the shared engine has no detected leakage, roadmap and ablation checks
pass, all three locale catalogs are complete, and cached P4 browser/server
latency regressions pass.

The uncached runner was also exercised three times with the existing synthetic
Telugu clip. It measured WER `0.20`, CER `0.16`, word accuracy `0.80`, first
audio p95 `17,542 ms`, and total-turn p95 `18,847.6 ms`. Because the clip is
synthetic and the uncached timings miss the `<1.5 s`/`<4 s` targets, this is
reported as `rehearsal_only`, not field accuracy or a release pass.

After adding the report privacy guards, a fresh single-sample synthetic run on
2026-09-30 measured WER `0.20`, CER `0.16`, first audio `9,376 ms`, and total
turn `12,064 ms`. This was rehearsal-only because the clip was synthetic.

The field rehearsal now uses a real Telugu recording from the Google FLEURS
`te_in` test split. Native speakers recorded each utterance; separate workers
checked whether the recording matched its source sentence, and invalid clips
were discarded. The reference is the source transcript prepared by human
translators. The corpus is CC BY 4.0: [dataset card](https://huggingface.co/datasets/google/fleurs),
[FLEURS paper](https://arxiv.org/abs/2205.12446). The selected clip is
`10054709042905280078.wav`; it was normalized to PCM16 for upload and was not
copied into the repository.

Five uncached runs measured mean WER `0.55`, CER `0.2342`, and word accuracy
`0.45`; first-audio p95 was `14,428.6 ms` and total-turn p95 was `14,428.8 ms`.
The report includes per-hop timings and review provenance but stores neither
transcript text nor audio. The cold accuracy and latency results are poor and
remain visible as follow-up signals; the build defines no numeric field WER or
cold-latency gate. The `<1.5 s`/`<4 s` release thresholds apply to cached clips,
whose P4 browser/server gates pass. P7 audit, human-recording rehearsal, and
evidence report are complete. The report records P7 as ready while full build
readiness remains open for the P2 catalog/CAT and embeddings gates and P3
live-index/source-breadth gates recorded in [STATE](STATE.md).
