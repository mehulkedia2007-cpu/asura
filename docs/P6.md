# P6 — evidence and polish

P6 adds the `/evidence` surface in all three locales and a read-only
`GET /engine/evidence` contract. The board is built from the actual frozen
regression fixtures, the cached P4 rehearsal report, the in-process telemetry
counters, the AST import-graph scan, and the committed taxonomy matcher.

It reports:

- shared student/rural engine counters and the purity/import-graph result;
- roadmap invariants and graph/vector matcher ablations;
- frozen P3 scheme precision plus a separately measured live-index score,
  scam confusion counts, grounding F1 and no-data violations;
- P5 interview and notice gates, P4 cached browser/server voice p95s, and
  three-locale key coverage;
- the 13 Constitution articles with status from deterministic behavior probes;
- the SHA and scope of the displayed evidence.

No network refresh, provider call, or database mutation is performed by the
evidence endpoint. Empty live voice samples are shown as empty; cached
rehearsals are labelled as cached. The golden corpus remains a development
regression set, not field validation. Each Constitution article has a named
API regression test; the endpoint's status probes exercise the corresponding
guardrail on each request.

## Reproduce

```sh
cd apps/api
uv run pytest -q tests/test_evidence.py
uv run ruff check .
uv run pyright

cd ../web
pnpm lint
pnpm typecheck
pnpm build
```

With the API and web app running, open `/en/evidence`, `/te/evidence`, or
`/hi/evidence`. The shared header navigation links to the screen from every
product surface.
