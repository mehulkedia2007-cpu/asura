# Autonomous execution

Work autonomously until the requested task is fully complete.

Do not stop after intermediate steps to ask whether you should continue.

When implementing a feature:

1. Inspect the existing project.
2. Make the required changes.
3. Run relevant checks and tests.
4. Fix problems you find.
5. Continue until the requested feature is complete.
6. Report back only when finished or genuinely blocked.

Do not ask for confirmation between normal implementation steps.
